# Definition of Done

## Purpose

The Definition of Done describes the minimum quality criteria that a work item should meet before it can be considered complete.

It helps teams align expectations, reduce rework, and improve delivery consistency.

## General Definition of Done

A task, feature, or change can be considered done when:

- The requirement is understood and implemented.
- The code or configuration change is complete.
- The solution was tested.
- The pull request was reviewed and approved.
- Documentation was updated when needed.
- No sensitive information was included.
- Acceptance criteria were met.
- Known risks or limitations were documented.
- The change is ready for release or deployment.

## Functional Validation

The team should confirm:

- The expected behavior works.
- Main business scenarios were tested.
- Error or edge cases were considered.
- The change does not break existing behavior.

## Technical Validation

The team should confirm:

- Code is readable and maintainable.
- The solution follows team standards.
- The change does not introduce unnecessary complexity.
- Important logs, errors, or validations are considered.
- Dependencies are justified.

## Security and Privacy Validation

The team should confirm:

- No credentials are committed.
- No tokens or API keys are included.
- No private customer data is exposed.
- Sensitive information is protected.
- Access control impacts were reviewed if applicable.

## Documentation

Documentation should be updated when the change affects:

- Setup instructions
- Configuration
- Business rules
- API behavior
- Release notes
- User flows
- Operational procedures

## Done vs. Almost Done

A change is not done if:

- It still requires unplanned manual fixes.
- It was not reviewed.
- It was not tested.
- It lacks required documentation.
- It contains unresolved critical risks.
- Acceptance criteria are incomplete.

## Final Principle

Done means ready to be used, reviewed, maintained, and released with confidence.

It does not mean "the code was written." That is only one part of the delivery process.
